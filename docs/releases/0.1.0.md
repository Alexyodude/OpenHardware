# OpenHardware 0.1.0

The first release, and the first copy of OpenHardware anyone can open
without installing anything: the emulator page, built as plain files that
run entirely in your browser tab.

**https://alexyodude.com/OpenHardware/**

## What it is

The page `python webui/emulator_server.py` serves on `127.0.0.1:8088`, with
the server moved into the tab. Its Python -- the same session code the
server runs -- runs under Pyodide in a Worker, and the CPU cores are compiled
to WebAssembly and loaded by that Python exactly as it loads them natively.
The page's own requests are answered inside the tab; nothing you load is
sent anywhere.

In it you can:

- run the i8086 sample programs, with registers, flags, memory and
  disassembly, stepping or running;
- pick a board and run a firmware image you built yourself on it, with its
  pins, its console and the 3D bench. Checked in a browser on an Arduino Uno
  blinking pin 13 and on a XIAO RP2040 printing to its console.

## What this copy cannot do

- **Compile a sketch.** That needs a toolchain, and this copy has none. The
  Build button is disabled and the page says so; run
  `python webui/emulator_server.py` from a checkout to build. A compiler in
  the tab is being worked on.
- **Search build artefacts**, which reads the server's disk.
- **Drive PICSimLab.** Its boards and the bridge page are not in it:
  PICSimLab is GPL, and shipping it would distribute GPL code. Run it locally
  with `webui/bridge.py`, as before.
- **Draw a vendor's 3D model, or offer a part on the bench, on the hosted
  copy.** Models are built per machine and the hosted build has none, so
  every board draws as its footprint, and the bench's part list is empty and
  says to run a tool a visitor cannot run. A copy you build yourself
  draws each model whose licence lets it be published; `tools/site_licences.py`
  decides which, model by model.
- **Run a board anywhere near real time** -- nor can the local server's
  page, which this copy nearly keeps up with. The page's status
  line says how far behind it is. Measured in Chromium on the machine this
  was built on, the Uno running a blink: about 200,000 instructions a
  second here, 1/78 of real time, against about 250,000 and 1/64 from the
  local server. A sketch that blinks every 500 ms toggles about every 40
  seconds.
- After you pick a board, the disabled Build button's tooltip talks about a
  compile recipe instead of saying compiling needs the local server.
- It has been tested in Chromium only.

## Size

Measured on 2026-10-16, on a build from a clean checkout of this release
with no 3D models, as the hosted copy is built:

| part | bytes |
|---|---:|
| Pyodide 314.0.7 (CPython 3.14.2) | 13,531,207 |
| the page and its scripts, three.js included | 2,696,958 |
| `openhardware.zip`: this repository's Python and the four cores | 580,229 |
| licence texts (`NOTICE.txt`) | 170,659 |
| `models/`: an empty index and its notice | 609 |
| **total** | **16,979,662** |

A build with one machine's 3D models in it was 35,320,330 bytes, the models
18,341,921 of that.

## Licences

The site redistributes what it serves, so each file it ships is one whose
licence allows that. `NOTICE.txt` beside the page carries every licence of
the runtime whole -- Pyodide's (MPL-2.0), CPython's, and those of
Emscripten's libraries -- and `models/NOTICE.txt` names each 3D model, whose
board file it was drawn from, and the licence it is published under.
`PROVENANCE.md` has the reasoning. OpenHardware itself is MIT.

## Building it yourself

From a clone of the repository -- not the release's source archive, which
carries no git history: the page states the commit it was built from.

```bash
git clone https://github.com/Alexyodude/OpenHardware && cd OpenHardware
git checkout v0.1.0
python tools/build_core.py
python tools/build_site.py          # needs Emscripten 5.0.3 in third_party/emsdk
python -m http.server -d build/site 8123
```

`tools/build_site.py`'s docstring says what goes in and from where, and
`.github/workflows/pages.yml` is the whole build as CI runs it. The page's
notice ends "This is OpenHardware 0.1.0, built from" and the commit; a build
from an edited tree adds "with local changes".
