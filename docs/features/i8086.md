Oracle shorthand used below:

- **SST8088** — `SingleStepTests/8088`, MIT, hardware-generated from an AMD
  D8088 (1982) in Maximum Mode. 10,000 tests per opcode for standard
  instructions, 2,000 for string ops, 1,000 for flag ops. Each case carries
  initial and final register and memory state, and a per-cycle bus trace. The
  ISA is identical to the 8086, so register and memory results transfer
  exactly; **cycle and bus data do not** — see `i8086.dec0.target-8088`.
- **Intel manual** — *Intel 8086 Family User's Manual*, instruction and flag
  tables.
- **board.h** — the pure-virtual contract in `src/lib/board.h`; the oracle is
  that the class compiles and the board loads and runs.
- **rcontrol** — the remote-control command surface in `src/lib/rcontrol.cc`.
