Oracle shorthand used below:

- **SST8088** — `SingleStepTests/8088`, MIT, hardware-generated from an AMD
  D8088 (8441DMA, 1982) in Maximum Mode via the Arduino8088 interface. Each
  case carries initial and final register and memory state, and a per-cycle bus
  trace. The ISA is identical to the 8086, so register and memory results
  transfer exactly; **cycle and bus data do not** — see
  `i8086.dec0.target-8088`.

  Case counts, corrected against the corpus README on 2026-08-12 — the earlier
  summary here listed three of the five tiers and would have made a harness
  report suspiciously few cases without saying why. Standard opcodes carry
  10,000 cases each; shift and rotate by CL (`D2`, `D3`) carry 5,000; string
  operations 2,000; `INC`/`DEC` with a fixed register (`40`-`4F`) 1,000; and
  flag operations (`F5`, `F8`-`FD`) 1,000.

  *(Stated as prose, not a table: this file may hold exactly one table, because
  `tools/ledger.py` parses every pipe-delimited row it finds. Writing that
  second table is how this note came to be here — the parser rejected the file
  rather than silently reading five case-count rows as broken ledger cells.)*

  **`v2` holds 324 files, not 256.** Group opcodes are split by their modrm.reg
  extension — `80.0.json.gz` through `80.7.json.gz` — so a harness iterating
  `00`..`FF` would silently skip every group instruction.

  **`final` is a delta, not a state**: it lists only what changed. Comparing
  against it directly checks one or two registers and calls that a pass.
  `tools/sst8088.py` merges it over `initial`; `test_final_is_a_delta_and_is_
  merged_into_a_whole_state` pins that.
- **Intel manual** — *Intel 8086 Family User's Manual*, instruction and flag
  tables.
- **board.h** — the pure-virtual contract in `src/lib/board.h`; the oracle is
  that the class compiles and the board loads and runs.
- **rcontrol** — the remote-control command surface in `src/lib/rcontrol.cc`.
